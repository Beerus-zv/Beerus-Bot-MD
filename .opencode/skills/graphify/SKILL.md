# Graphify

## Cuándo usar
- Cuando el usuario pida mapear, indexar o entender las relaciones del repositorio actual.
- Si ya existe la carpeta 'graphify-out/' en la raíz del proyecto.

## Comandos Principales
- /graphify . : Escanea el directorio actual y genera el mapa visual e índice de relaciones (graphify-out/).
- graphify query <pregunta> : Consulta de forma inteligente la base del grafo sin releer archivos planos.
